# AirNanny Local

Локальная интеграция Home Assistant для бризеров AirNanny A7: без облака, устройство подключается
напрямую к Home Assistant.

## Как это работает

Интеграция поднимает TCP-сервер на порту **3001**. Бризер сам подключается к нему, представляется
своим идентификатором (MAC), после чего Home Assistant каждые 5 секунд опрашивает его состояние
и отправляет команды. Порт 3001 на хосте Home Assistant должен быть доступен бризеру.

## Установка

### HACS

1. HACS → меню → «Пользовательские репозитории».
2. Добавьте `https://github.com/alexeykin1984/airnanny-local` с типом «Интеграция».
3. Установите «AirNanny Local» и перезапустите Home Assistant.

### Вручную

Скопируйте папку `custom_components/airnanny_local` в `config/custom_components/` и перезапустите
Home Assistant.

## Настройка

1. «Настройки» → «Устройства и службы» → «Добавить интеграцию» → «AirNanny Local».
2. Укажите имя и MAC-адрес бризера.

Остальные бризеры добавляются и удаляются в настройках интеграции («Настроить»). Если к серверу
подключается неизвестный бризер, появится уведомление с его MAC-адресом.

## Сущности

Для каждого бризера создаются:

| Сущность | Что делает |
| --- | --- |
| `climate` | Режим (выключен / вентиляция / авто), целевая температура, скорость вентилятора 0–6, текущие температура и влажность |
| `sensor` CO2 | Уровень CO2, ppm |
| `number` Влажность | Ступень увлажнения 0–3 |
| `switch` Ночной режим | Ночной режим |
| `switch` Заслонка | Открыть / закрыть заслонку |
| `binary_sensor` Наличие воды | Сигнал об отсутствии воды |

Пока бризер не подключён, его сущности недоступны.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements_test.txt
.venv/bin/pytest
```

Тесты запускают настоящий Home Assistant и эмулятор бризера, который подключается по TCP
(на порту 39001, чтобы не мешать работающему Home Assistant).
